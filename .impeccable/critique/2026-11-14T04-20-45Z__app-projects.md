## Priority Issues

### [P1] Framed thumbnails
- **Why it matters:** The 4.5rem box adds a border, radius, and surface fill. The style guide and the writing index both leave that chrome out. On a phone the square stays beside the text, the beanie becomes a horizon line, and Kai’s tile is a GitHub mark that names a host.
- **Fix:** Drop the media column. Make the row the writing row: the display title is the only link, and one meta value sits in the trailing code slot. If a picture is the work, show it uncropped on the project page.
- **Suggested command:** /impeccable layout

### [P1] “tool” does not earn the date column
- **Why it matters:** Writing’s trailing value changes every row. Here three rows say “tool,” so the column never helps a choice.
- **Fix:** Put a real distinguisher there, the way a date works: a year, or a role that is actually different. If four different kinds cannot be named, omit the slot.
- **Suggested command:** /impeccable clarify

### [P2] Blurbs make the index heavier than the essays index
- **Why it matters:** The useful line on Fractal Generator is trapped in parentheses. The backtester line reads like a changelog. Writing withholds the essay until the click, which is why that list feels sharp.
- **Fix:** Title-only links. If one line must stay, one clause in the small size, outside the link, with no parentheses.
- **Suggested command:** /impeccable distill

### [P2] The whole card is one link, and Kai does not say it leaves
- **Why it matters:** The accessible name is title, kind, and the full blurb. Kai uses that same shape and opens a new tab.
- **Fix:** Link only the title, as the writing entry does, and leave meta beside it. Name the external row in the link (“Kai, on GitHub”).
- **Suggested command:** /impeccable clarify

### [P3] Narrow layout stacks the kind between title and blurb
- **Why it matters:** At a phone width the title row becomes one column, so “tool” splits the title from the sentence. Writing stacks the date after the title, which reads as metadata.
- **Fix:** Keep title then description, and place the meta after the title in muted Inconsolata.
- **Suggested command:** /impeccable adapt
